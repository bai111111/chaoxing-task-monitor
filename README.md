# 学习通任务监听 (autoanswer-chaoxingxuexitong)

一个 [ZCode](https://zcode.ai) 技能（Agent Skill）：**挂机监听超星学习通（Chaoxing）课程的「任务」**——随堂练习、签到、章节测验等老师随时布置的活动。一旦出现新任务，自动唤醒 AI 助手在浏览器里完成，然后继续监听，循环往复，直到你叫停。

> 一次性清完现有作业/考试是另一个技能（chaoxing-homework）的事；本技能专注"挂着等新任务、来了就自动做"。

## 功能特性

- **自动登录**：复用 Windows DPAPI 加密保存的账号密码，打开网页即自动登录（也可选择扫码/手动登录，AI 不读取不记录任何凭据）
- **课程识别与选择**：自动读取个人空间全部课程，以编号列表或多选框让你挑选要监听的课程
- **持续监听**：默认只监听课程的「任务」列表（作业/考试默认不监听，需要时可要求纳入）
- **自动完成**：新任务出现立即唤醒 AI 用浏览器进入课程完成；作业类按 ≥90% 分数标准、查看解析自动重做；考试提交前会先给你确认
- **两种监听模式**（按环境自动选择，详见下文）
- **全程汇报**：每轮巡检简报一句，停止时汇总监听时长、完成任务与得分

## 工作原理

```
登录 → 选课 → 建立任务基线 → 清完存量任务 → 持续监听 → 新任务自动完成 → 回到监听
```

两种监听模式由脚本 `scripts/monitor_tasks.py` 实现，按部署环境自动选择：

| 模式 | 机制 | 适用 |
|---|---|---|
| **爬虫轮询**（默认） | 用会话 cookie 直接 GET 任务列表接口，与快照哈希比对；发现新任务以退出码 2 退出，唤醒 agent | 标准超星账号，爬虫可自行续登录 |
| **定时巡检**（兜底） | 脚本退化为纯定时器（默认 15 分钟），到点唤醒 agent 用浏览器巡检列表 | 校园版 v8 等部署：浏览器 httpOnly cookie 导不出、学校托管密码不通用超星通行证接口、登录强制滑块验证码 |

> 为什么会有兜底模式：部分学校的 v8 平台由校方托管密码，超星通行证接口会返回"用户名或密码错误"；且浏览器 API 不暴露 httpOnly cookie，爬虫拿不到完整会话。此时由浏览器（自带完整登录态）承担巡检，脚本只负责定时。

浏览器自动化由 ZCode 内置的 browser-use（control-browser）能力承担：打开页面、读 DOM、点击、填表、截图全部走内置浏览器，首次登录遇到滑块验证码也能自动拖动完成。

## 安装

把整个目录复制到 ZCode 的技能发现路径之一：

```
~/.agents/skills/autoanswer-chaoxingxuexitong/     # 用户级，所有项目可用（Windows: C:\Users\<你>\.agents\skills\...）
<项目>/.agents/skills/autoanswer-chaoxingxuexitong/ # 项目级
```

依赖：

- Windows（凭据读写用 PowerShell + DPAPI）
- Python 3.8+，`pip install requests`；可选 `cryptography`（爬虫模式自动续登录用）
- ZCode（含 browser-use 能力）

## 使用方法

在 ZCode 对话里直接说：

- 「帮我挂机监听学习通课程任务」
- 「监听高数课，有新任务自动做完」
- 「监听任务间隔改成 5 分钟」
- 「停止监听」

首次使用流程：

1. 打开 v8.chaoxing.com，检测到已保存账密则自动登录；没有则让你选"提供账密（加密保存，以后自动登录）"或"自行扫码登录"
2. 列出进行中的课程（编号 1、2、3……），你回复编号即可，如 `1,3`
3. 进入所选课程建立任务基线；如已有未完成任务会直接先做完再开始挂机
4. 启动监听（爬虫轮询 200 秒/次，或定时巡检 15 分钟/轮），上限默认 6 小时，到点询问是否续挂
5. 期间随时可以对话；发现新任务会先报告再自动完成；说"停止"随时结束并汇总

## 凭据安全

- 密码通过 `scripts/auth.ps1` 用 **Windows DPAPI（CurrentUser 范围）** 加密后存入 `%USERPROFILE%\.chaoxing\auth.json`，不落明文
- DPAPI 保护边界：同机其他 Windows 用户和被拷走的文件解不开；但**当前 Windows 用户**下运行的程序（包括本技能）仍可解密——这是自动登录的前提
- 选择"自行登录"方式时，AI **不读取、不记录、不保存**你输入的任何凭据
- 监听配置文件含会话 cookie，技能结束时建议清理（技能流程已内置此习惯）
